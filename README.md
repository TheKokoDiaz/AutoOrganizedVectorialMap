# Mapa auto-organizado
**Evidencia:** 233110696_SOM_C1

**Elaborado por:** Julio Alfredo Vázquez Díaz

Este proyecto, presenta un modelo capaz de organizar animales en mapa vectorial de acuerdo a las caracteristicas de estos. Como mejora entregable se realizaron los siguientes cambios:
- El mapa pasó de 2D a 3D.
- Se incrementó la cantidad de caracteristicas a 20.
- Los animales ahora se muestra en el mapa usando emojis.
- Es posible modificar los hiperparámetros de épocas y la tasa de aprendizaje.
- Los animales se añaden automaticamente al completar el formulario.

## Base del modelo original
La versión base de este programa, fue desarrollado por el Mtro. Samuel Mendez Vega, en el archivo **som_base.php**. Gracias a esta base y a la documentación otorgada por él, fue posible realizar las respectivas mejoras al programa.
